# Contract One

Portrait browser survival bullet heaven. Play: https://esetebanjimenez.github.io/contract-one/

`pnpm install`, then `pnpm dev`. Checks: `pnpm lint`, `pnpm format:check`, `pnpm test`, `pnpm build`.
Tuning values live in `src/data/`. The sim (`src/sim/`) is deterministic and never imports render, UI or pixi.js.
